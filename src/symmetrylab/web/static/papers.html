03 Interest map

0 anchors
How ranking works

Each keyword and paper is an anchor (Q). Papers are keys/values (K = V). Attention = softmax(cos(anchor, paper) / 0.12) assigns each vote to anchors; likes pull an anchor, dislikes push it, limited to 25°. Likes no anchor explains are flagged as emerging interests. Ported from Newspaper's anchored multi-interest profile; no model is trained.
