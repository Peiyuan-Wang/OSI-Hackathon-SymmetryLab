# SymmetryLab v0.3.2 — Valency Bond MCP

Paper survey can now search arXiv, Valency Bond, or both. Results retain source attribution, reuse existing ranking and feedback, and are deduplicated by arXiv ID or DOI. A failure from one source preserves results from the other.

## Download and launch

- **Windows 10/11 x64:** download `SymmetryLab-windows-x64.zip`, extract the entire archive, then double-click `SymmetryLab/SymmetryLab.exe`. Keep `_internal` beside the executable. Microsoft Edge WebView2 Runtime is required.
- **Apple Silicon macOS:** download `SymmetryLab-macos-arm64.zip`, extract it, then open `SymmetryLab.app`. The app is not notarized; first launch may require right-click → Open or approval in macOS Privacy & Security.
- Both packages include Python and the verified **SSG Reciprocal Offline 0.1.5 catalog (67,475 records)**. No separate `.sqlite` download or command-line startup is needed.
- Each ZIP has a companion SHA-256 file. These lite builds omit optional PyTorch/PhysBERT and use the local lexicon for paper ranking.

## Use Valency Bond MCP

1. Sign in to [Valency Settings](https://app.valency.io/settings) and obtain a bearer token. See the official [Direct API guide](https://docs.valency.io/guides/api/).
2. Open **Paper survey → Literature sources · Valency Bond MCP**.
3. Choose **arXiv + Valency Bond** or **Valency Bond**, paste the token, and click **Test Bond connection**. This calls `list_sources` through `https://mcp.valency.io/` using Streamable HTTP.
4. Add physics interest keywords and click **Find papers**. The adapter discovers and invokes `semantic_search_papers`.

The token stays in the current app session and must be entered again after restarting. It is not included in packages, survey files or reports. Developers can alternatively supply `SYMMETRYLAB_BOND_TOKEN` in the app's environment.

With **Physics categories only** enabled, records without recognized physics categories are omitted. Uncheck it to include them. Existing saved papers remain when switching sources.

## Validation and limits

- Local regression: **149 passed, 1 skipped** (optional PhysBERT). Release automation also runs regression and frozen-app checks on native Windows and macOS runners before uploading assets.
- Frozen checks verify packaged Bond modules and UI resources, offline calculations/designs and the bundled SSG catalog. They do not certify native window rendering on every machine.
- **Authenticated Bond search has not been validated with a live user token.** Tests use synthetic MCP responses. A successful connection test does not by itself verify actual search compatibility or coverage beyond arXiv.
- Bond currently serves **Paper survey**; the Theory/Experiment agent's separate retrieval tools do not call it. OAuth login, token refresh and full-text retrieval remain unimplemented.
- Existing v0.3.1 releases and the SSG data release remain available.
