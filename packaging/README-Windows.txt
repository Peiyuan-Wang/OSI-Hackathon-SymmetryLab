SymmetryLab for Windows 10/11 x64

Extract the entire ZIP, then double-click SymmetryLab.exe inside the SymmetryLab folder.
Keep _internal beside the executable. Python and a command prompt are not required.
Microsoft Edge WebView2 Runtime is required (included on most current Windows systems).
If missing, install it from https://developer.microsoft.com/microsoft-edge/webview2/ .

Use Offline demonstration first. Configure your own API service on Connection for live research.
Data and saved settings are stored in %APPDATA%\SymmetryLab, not inside the program folder.
The build does not contain anyone's API key, papers or research history.
Default builds omit PyTorch/PhysBERT; the paper survey uses the offline lexicon.
This preview is unsigned. Only run packages from a source you trust.
